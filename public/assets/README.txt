Replace the SVG placeholders with your own images, keeping these filenames or updating src/data/invitation.ts:
- groom.svg -> groom photo (recommended: groom.jpg)
- bride.svg -> bride photo (recommended: bride.jpg)
- story-1.svg, story-2.svg, story-3.svg -> engagement/story photos
- Add music.mp3 only if you have permission to use that audio.

Files in public/assets are deployed with the static site and referenced as /assets/filename.ext.
For best performance, resize photos to around 1200px on the longest side and compress them before committing.
